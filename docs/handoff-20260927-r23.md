## 可重現測試與限制

- `tests/test_ipv6_options.c`：157 parser boundary cases；整合於 core regression。
- `bash tools/linux-ipv6-options-test.sh /path/to/fakesip`：需 root、Linux、
  Python3、iproute2、util-linux、nftables 與 veth；只操作新 namespace。
- `python3 tests/netns_exec.py /path/to/fakesip`：同一 wire test 的 portable
  runner，免 unshare/nsenter 指令，仍需要 kernel namespace/veth 支援。
- 原始 `docs/experiments/upstream-audit-20260927/` 僅用於 r22 的歷史診斷，
  不能對 r23 執行後把「不再重現」誤判為新故障。
- 只支援 Hop-by-Hop／Destination Options；最多 16 個 header，Hop-by-Hop
  只能在第一個。未支援類型、分片及 jumbogram 原包放行但不產生 decoy。
- 沒有證明真實 WAN 曾帶此擴充標頭；router 不支援 veth，沒有聲稱實機
  完成六組 extension wire case，也沒有長時間或高吞吐保證。
